Відкрийте `index.html` у браузері. Усі дані зберігаються в `data.js`; працює без серверу.

## Як додавати записи

В `data.js`, у масиві `PORTFOLIO_ENTRIES`, один об'єкт — один **верхній рядок**. Головні поля:

```js
{
  id: 'unique-id',
  group: 'життя',  // 'робота' | 'життя' | 'хобі'
  date: '03-21',   // 'MM-YY', 'YYYY' або ''
  title: 'Заголовок',
  preview: 'assets/image.jpg', // необов'язково
  facts: [['Опис', 'Текст']]   // докладна інформація у розкритому рядку
}
```

Для групи з підрядками, наприклад **Захоплення**, замість `facts` можна використовувати `subsections`:

```js
subsections: [
  { title: 'Art', date: '2010', description: 'Малювання' },
  { title: 'Digital art', date: '2020', description: 'Цифрове малювання' }
]
```

Рік невідомий? Залишайте `date: ''`. Для точної дати, яка в колонці має відображатись як місяць/рік, можна додати `dateISO: '2020-08-07'` (корисно для точного сортування).

Не потрібно змінювати `script.js` або `styles.css` щоразу, коли додається новий пункт чи підрозділ.
